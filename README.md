# 写真暗室 現像・停止・定着工程ガイド

フィルム種別（Kodak Tri-X/Ilford HP5/T-Max/Neopan Acros/カスタム）と現像液（D-76/HC-110/Rodinal/ID-11/カスタム）、現像温度（18〜24℃）を選択すると、現像・停止・定着・水洗の4工程の最適時間を自動算出します。工程トラッカーでは各浴のカウントダウンタイマーと撹拌アラートをリアルタイム表示し、印画紙焼付け時の露光メモはlocalStorageに保存できます。

## 機能
- フィルム×現像液×温度の組み合わせから現像時間を自動ルックアップ
- 温度補正対応（18〜24℃、0.5℃刻み）
- 4工程（現像/停止/定着/水洗）タイムテーブル表示
- SVGリングアニメーション付きカウントダウンタイマー
- 撹拌リマインダー（最初の30秒連続 → 30秒ごと5回反転）
- 工程ステージインジケーター（現在工程のハイライト）
- 印画紙焼付けメモ（コントラスト/露光時間/覆い焼き・焼き込みメモ）のlocalStorage保存・削除
- カスタムフィルム・現像液対応
